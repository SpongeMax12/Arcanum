**TASK**

Your task is to process a list of French expressions based on a provided context. For each expression, you will generate a corresponding block of text formatted for Anki import. You **MUST** process every expression from the `{EXPRESSIONS}` list in the exact order provided. Do not add, omit, or reorder any expressions. The number of output cards must exactly match the number of expressions in the input.

**OUTPUT SPECIFICATION**

Each card must be a block of text starting with `---START-CARD---` and ending with `---END-CARD---`. The nine fields within each card **MUST** be separated by `:::`. The order of fields must be exactly as follows:

1.  `TargetWord`
2.  `ExampleSentence`
3.  `Options` (Four options separated by `::`)
4.  `CorrectOptionIndex`
5.  `IPA`
6.  `PartOfSpeech`
7.  `Explanation`
8.  `BaseForm`
9.  `Source`

**PROCESSING STEPS & RULES**

For each expression in the `{EXPRESSIONS}` list, create one card block by following these rules meticulously:

1.  **`TargetWord`**: The expression in this field **MUST be an *exact, case-sensitive substring* of how it appears in the `ExampleSentence`**. This is critical for display purposes. You must adapt the original expression from the `{EXPRESSIONS}` list to achieve this.
    *   **Example 1 (Noun):** If the original expression is `le thé` but the sentence is `Je bois une tasse de thé vert.`, the `TargetWord` **MUST** be `thé`.
    *   **Example 2 (Verb):** If the original expression is `aller` but the sentence is `Nous sommes allés au marché.`, the `TargetWord` **MUST** be `sommes allés`.
    *   **Example 3 (Adjective):** If the original expression is `vert` but the sentence is `J'aime les voitures vertes.`, the `TargetWord` **MUST** be `vertes`.
    *   **Duplicate Handling:** If multiple cards have the same final `TargetWord`, add a subtle, inconspicuous symbol (like a period `.`, a zero-width space, or a similar character) to the end of the duplicate `TargetWord` entries to ensure uniqueness for Anki import (e.g., `maison`, `maison.`, `maison..`).

2.  **`ExampleSentence`**: Find the clearest sentence from the `{CONTEXT}` that contains the expression. If no suitable sentence is found in the context, you **MUST** generate a new, simple, and grammatically correct example sentence that clearly illustrates the expression's meaning.

3.  **`Options` & `CorrectOptionIndex`**: This is a critical multi-step process:
    a.  **Create the Correct Answer**: Write a concise and accurate English definition of the `TargetWord` as used in the `ExampleSentence`.
    b.  **Create Three Plausible Distractors**: Generate three incorrect but believable options.
    c.  **Shuffle and Format**: Combine the correct answer and the three distractors into a single string, separated by `::`.
    d.  **Set the Index**: The `CorrectOptionIndex` **MUST** be the 0-indexed position (0, 1, 2, or 3) of the correct answer in the shuffled `Options` string. **Crucially, ensure the position of the correct answer is genuinely randomized and does not follow a predictable pattern.**

4.  **`IPA`**: Provide the International Phonetic Alphabet (IPA) transcription for the `TargetWord`.

5.  **`PartOfSpeech`**:
    *   If the expression is a single verb OR a phrase with a main verb (e.g., "sont allés"), the value **MUST** be `verb`.
    *   For all other cases, the value **MUST** be `other`.

6.  **`Explanation`**: Generate a detailed explanation as a single HTML string. The structure **MUST** perfectly match the format required by the user's CSS for proper rendering. Use this exact structure:
    `<p><b>[Icon] Title:</b> [Content for this section. Use <br> for line breaks *within* the content itself, but NOT after the title tag.]</p><p><b>...</b></p>...`
    Ensure all tags are properly closed.

7.  **`BaseForm`**:
    *   If `PartOfSpeech` is `verb`, this field **MUST** contain the main verb's infinitive, stripped of reflexive pronouns (e.g., "battre" for "se battre", "aller" for "sont allés").
    *   If `PartOfSpeech` is `other`, this field **MUST** be left EMPTY.

8.  **`Source`**: Use the static source string provided in `{SOURCE}`.
