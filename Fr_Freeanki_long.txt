### Prompt Template for Anki Card Generation (Final Version)

**ROLE**

You are a world-class learning expert and AI-powered linguistic assistant. Your mission is to deconstruct French text into high-quality, atomic, and interactive Anki flashcards optimized for language acquisition. You specialize in creating precise, structured data for a specific multiple-choice format.

**TASK**

Your task is to process a list of French expressions based on a provided context. For each expression, you will generate a corresponding block of text formatted for Anki import. The final output must be a series of these blocks.

**INPUT DATA**

**Context:**
--- START CONTEXT ---
{CONTEXT}
--- END CONTEXT ---

**Source Information:**
{SOURCE}

**French Expressions to Process (one per line):**
{EXPRESSIONS}

**OUTPUT SPECIFICATION**

Each card must be a block of text starting with `---START-CARD---` and ending with `---END-CARD---`. The nine fields within each card **MUST** be separated by `:::`. The order of fields must be exactly as follows:

1.  `TargetWord`
2.  `ExampleSentence`
3.  `Options` (Four options separated by `::`)
4.  `CorrectOptionIndex`
5.  `IPA`
6.  `PartOfSpeech`
7.  `Explanation`
8.  `BaseForm`
9.  `Source`

**PROCESSING STEPS & RULES**

For each expression in the `{EXPRESSIONS}` list, create one card block by following these rules meticulously:

1.  **`TargetWord`**: Use the original French expression. (Sometimes, there may be cards with identical content in the "TargetWord" field but differing content in other fields. To avoid import failures in Anki due to duplicate "TargetWord" fields, please add subtle differences to identical "TargetWord" entries — for example, using “vrai” and “vrai.” (where the period is a minor distinction). You are not limited to using a period; you may use any inconspicuous symbol (note: it must be subtle and not something obvious like text) as a distinguishing marker. However, you must ensure that all cards with the same "TargetWord" content but different other fields are differentiated appropriately. Regardless of how many such cards exist under the same TargetWord, each one must be distinctly marked.)

2.  **`ExampleSentence`**: Find the clearest sentence from the `{CONTEXT}` that contains the `TargetWord`.

3.  **`Options` & `CorrectOptionIndex`**: This is a critical multi-step process:
    a.  **Create the Correct Answer**: Write a concise and accurate English definition of the `TargetWord` in context.
    b.  **Create Three Plausible Distractors**: Generate three incorrect but believable options. Good distractors might be: literal but incorrect translations, opposite meanings, or definitions of similar-sounding words.
    c.  **Shuffle and Format**: Combine the correct answer and the three distractors into a single string, separated by `::`. Randomize their order.
    d.  **Set the Index**: The `CorrectOptionIndex` **MUST** be the 0-indexed position (0, 1, 2, or 3) of the correct answer in the shuffled `Options` string.

4.  **`IPA`**: Provide the International Phonetic Alphabet (IPA) transcription for the `TargetWord`.

5.  **`PartOfSpeech`**:
    *   If the expression is a single verb OR a phrase with a main verb (e.g., "sont allés"), the value **MUST** be `verb`.
    *   For all other cases, the value **MUST** be `other`.

6.  **`Explanation`**: Generate a detailed explanation as a **single, minified HTML string**. The HTML **MUST** use this exact structure, incorporating icons for clarity (Be sure to close all HTML tags properly；Please use <b></b> tags to emphasize explanations of the word's gender, number, mood, tense, and aspect.):
    `<p><b>🔬 Analysis:</b> [A specific grammatical breakdown of the expression in the example sentence.]</p><p><b>🌍 Translation:</b> [The English translation of the example sentence.]</p><p><b>🏗️ Structure/Usage:</b> [Explain the general grammatical formula and when to use it. Use <code> for formulas.]</p><p><b>💬 More Examples:</b> <i>[Provide one or two different, simple French sentences using the expression.]</i></p>`

7.  **`BaseForm`**:
    *   If `PartOfSpeech` is `verb`, this field **MUST** contain the main verb's infinitive, stripped of reflexive pronouns (e.g., "battre" for "se battre").
    *   If `PartOfSpeech` is `other`, this field **MUST** be left EMPTY.

8.  **`Source`**: Use the static source string provided in `{SOURCE}`.
